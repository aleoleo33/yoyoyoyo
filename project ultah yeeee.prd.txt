# Product Requirements Document (PRD)

## Project

Birthday & 2 Month Anniversary Website ❤️

---

## Overview

Create a romantic single-page website as a birthday gift and 2-month anniversary celebration.

The website should feel like a journey through memories, emotions, and appreciation rather than a traditional website.

Users experience the story through vertical scrolling sections with smooth transitions, flower animations, emotional messages, and a WhatsApp-style chat memory section.

No navbar.

No routing.

No external pages.

Everything exists in one continuous experience.

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Design
- Mobile First

# User Experience

The website consists of 6 fullscreen sections.

Each section occupies approximately 100vh.

Use CSS Scroll Snap.

Smooth scrolling is required.
